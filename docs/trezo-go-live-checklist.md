## الاختبارات التشغيلية الخمسة

### T1 — طلب صراف

- [ ] أنشأ المحاسب الطلب.
- [ ] اختيرت قناة الصراف.
- [ ] لم يكن الحساب البنكي مطلوباً.
- [ ] تم الإرسال للمراجعة.
- [ ] ظهر الرقم المرجعي والبيانات الصحيحة.

### T2 — طلب بنك

- [ ] اختيرت قناة البنك.
- [ ] رفض النظام الحفظ دون حساب بنكي.
- [ ] قُبل الحساب المرتبط بالمستفيد.
- [ ] ظهر البنك والحساب في التفاصيل والطباعة.

### T3 — دورة الاعتماد

- [ ] نفذ كل دور مرحلته فقط.
- [ ] مُنع الاعتماد الذاتي أو الإجراء غير المصرح.
- [ ] ظهر المسؤول التالي بعد كل انتقال.
- [ ] اكتملت الدورة حتى التنفيذ أو التدقيق حسب السياسة.

### T4 — الطباعة

- [ ] سند حديث.
- [ ] سند مختصر.
- [ ] سند رسمي.
- [ ] سند إداري نصي.
- [ ] الرقم والمبلغ والمستفيد والجهة والهاتف والقناة صحيحة.
- [ ] بيانات الشركة والكليشة صحيحة.
- [ ] لم تظهر بيانات طلب آخر.

### T5 — الدخول والصلاحيات

- [ ] نجح الدخول المحلي.
- [ ] فشل الرمز الخاطئ دون كشف معلومات حساسة.
- [ ] نجح الخروج وإعادة الدخول.
- [ ] منع الحساب المعطل من الدخول.
- [ ] تم تغيير الرمز المؤقت للحسابات النهائية.
- [ ] اختلفت الصلاحيات حسب الدور.

## قاعدة القرار

- **جاهز للإطلاق:** كل بند حرج ناجح ولا توجد ملاحظات عالية الخطورة.
- **جاهز بشروط:** توجد ملاحظات منخفضة الخطورة موثقة بمالك وموعد معالجة.
- **غير جاهز:** فشل أي اختبار في القنوات أو الاعتماد أو الصلاحيات أو الطباعة أو النسخ الاحتياطي.
