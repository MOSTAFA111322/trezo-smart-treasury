# دليل تشغيل TREZO للموظفين

## 1. المحاسب: إنشاء طلب صرف

من لوحة **نظرة عامة** افتح **طلب صرف جديد**. أدخل وصف الطلب والمبلغ والعملة، ثم اختر الشركة والمستفيد والسنة المالية وقناة الصرف.

عند اختيار **قناة البنك** يجب اختيار الحساب البنكي المرتبط بالمستفيد. أما **قناة الصراف** فلا تحتاج حساباً بنكياً. إذا لم يظهر حساب للمستفيد، يجب إضافته من **الجهات والبيانات** قبل إنشاء الطلب.

اضغط **إنشاء المسودة**. يحجز النظام الرقم المرجعي تلقائياً، ثم يمكن فتح الطلب وإضافة المرفقات وإرساله إلى المراجعة.

## 2. المراجع: فحص الطلب

افتح **طلبات الصرف** ثم اختر الطلبات الموجودة في حالة **قيد المراجعة**. افحص المبلغ والمستفيد والقناة والمرفقات. عند سلامة البيانات نفّذ إجراء المراجعة، أو أعد الطلب للتصحيح مع توضيح الملاحظة.

## 3. المدير المالي: الاعتماد

افتح صندوق الطلبات التي اجتازت المراجعة. راجع البيانات والمرفقات وسجل التدقيق، ثم نفّذ الاعتماد المالي أو أعد الطلب للتصحيح عند وجود نقص.

## 4. المدير العام: التنفيذ

افتح الطلبات المعتمدة، تحقّق من أمر الصرف والكليشة الرسمية والتوقيعات، ثم نفّذ الإجراء النهائي. بعد التنفيذ لا يُعاد تعديل الطلب كمسودة.

## 5. المتابعة والطباعة

يعرض **صندوق العمل اليومي** عدد المسودات التي تحتاج إجراء، والطلبات قيد المراجعة، والطلبات الجاهزة للتنفيذ. افتح أي بطاقة للانتقال إلى الطلبات.

من تفاصيل الطلب اختر قالب الطباعة المناسب. قالب الشركة الرسمي مخصص للتوقيعات والإجراء الخارجي، وقالب الأرشفة الداخلية مخصص للحفظ الورقي الداخلي. يجب مراجعة المعاينة قبل الطباعة.

## قواعد عملية مهمة

- لا تشارك حسابك أو جلسة الدخول مع موظف آخر.
- لا تستخدم قناة البنك دون حساب بنكي مرتبط بالمستفيد.
- لا تستخدم حساباً بنكياً مع قناة الصراف.
- سجّل ملاحظات التصحيح بوضوح حتى لا تتكرر دورة الإرجاع.
- راجع الرقم المرجعي قبل الطباعة والحفظ.
